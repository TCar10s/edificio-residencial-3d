# Edificio Residencial 3D

Modelo 3D interactivo de una edificación residencial de tres pisos con terraza, ubicada en Bogotá D.C. Proyecto de aula de Ingeniería Civil (UFPSO).

Permite ver el edificio completo o hasta un piso, separar los pisos, mostrar u ocultar el entorno y los nombres de cada espacio.

Sitio: https://tcar10s.github.io/edificio-residencial-3d/
